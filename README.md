# 📚 연수 관리 홈페이지

여러 교원 연수를 한곳에 등록하고 상태(신청 전 → 신청 완료 → 수강 중 → 이수 완료)를 관리하는 홈페이지예요.
빌드 과정 없는 정적 사이트(HTML/CSS/JS)이고 GitHub Pages로 공개돼요.

- 사이트 주소: https://deepsky616.github.io/teacher-training/

## 연수 추가·수정 방법

모든 연수 정보는 **`data/trainings.json` 한 파일**에 들어 있어요. 이 파일만 고쳐서 올리면 몇 분 뒤 사이트에 반영돼요.
파일은 연수 객체들의 배열(`[ ... ]`)이에요. 처음에는 빈 배열 `[]`이에요.

### 항목 설명

| 필드 | 뜻 | 예시 / 허용값 |
|---|---|---|
| `id` | 고유 번호(겹치지 않게) | `"2026-001"` |
| `title` | 연수명 | |
| `organizer` | 주관 기관 | `"서울특별시교육청교육연수원"` |
| `category` | 분야 | `"AI·디지털"`, `"생활지도"` 등 자유 |
| `start_date` | 시작일 | `"YYYY-MM-DD"` |
| `end_date` | 종료일 | `"YYYY-MM-DD"` (하루짜리면 시작일과 같게) |
| `time` | 시간 | `"15:00~17:00"` |
| `mode` | 방식 | `온라인` / `오프라인` / `혼합` |
| `location` | 장소 | `"연수원 3층 강당"`, 온라인이면 `"원격"` |
| `target` | 대상 | `"초등 교사"` |
| `hours` | 이수시간(숫자) | `15` |
| `apply_deadline` | 신청 마감일 | `"YYYY-MM-DD"` |
| `apply_url` | 신청 링크 | `"https://..."` |
| `status` | 진행 상태 | `신청 전` / `신청 완료` / `수강 중` / `이수 완료` / `마감` |
| `memo` | 메모 | 자유 |
| `updated_at` | 이 항목을 고친 날짜 | `"YYYY-MM-DD"` (가장 최근 값이 "마지막 업데이트"로 표시돼요) |

### 예시 (README 설명용 예시예요. 실제 데이터 아님)

```json
[
  {
    "id": "2026-001",
    "title": "예시: 초등 AI 디지털교과서 활용 연수",
    "organizer": "예시 교육연수원",
    "category": "AI·디지털",
    "start_date": "2026-11-10",
    "end_date": "2026-11-24",
    "time": "자율 수강",
    "mode": "온라인",
    "location": "원격",
    "target": "초등 교사",
    "hours": 15,
    "apply_deadline": "2026-11-05",
    "apply_url": "https://example.com",
    "status": "신청 전",
    "memo": "학교 공문 확인 후 신청",
    "updated_at": "2026-10-27"
  }
]
```

## 사이트 기능
- 상태별 개수 요약, 이수 시간 합계
- 다가오는 신청 마감 D-day
- 검색, 상태·방식·분야 필터, 날짜 정렬
- 카드 / 표 / 달력 보기, 클릭하면 상세 보기
