# 📚 청계초 정보 수집

신청할 수 있는 연수를 안내하고, 각 연수의 신청 페이지(예: 구글 설문지)로 연결해 주는 공개 홈페이지예요.
빌드 과정 없는 정적 사이트(HTML/CSS/JS)이고 GitHub Pages로 공개돼요.

- 사이트 주소: https://deepsky616.github.io/teacher-training/

> 이 저장소와 사이트는 **누구나 볼 수 있어요.** 개인 진행 상태(신청 완료·수강 중·이수 완료), 메모 같은
> 관리자용 정보는 여기에 넣지 않고 따로 비공개로 관리해요.

## 연수 추가·수정 방법

공개 연수 정보는 **`data/trainings.json` 한 파일**에 들어 있어요. 이 파일만 고쳐서 올리면 1~2분 뒤 사이트에 반영돼요.
파일은 연수 객체들의 배열(`[ ... ]`)이에요. 처음에는 빈 배열 `[]`이에요.

### 항목 설명 (모두 공개되는 정보예요)

| 필드 | 뜻 | 예시 / 허용값 |
|---|---|---|
| `id` | 고유 번호(겹치지 않게) | `"2026-001"` |
| `published` | 사이트에 보일지 여부 | `true` / `false` (`false`면 숨김) |
| `title` | 연수명 | |
| `description` | 짧은 소개(1~2문장) | |
| `organizer` | 주관 기관 | `"○○교육연수원"` |
| `category` | 분야(필터에 쓰여요) | `"AI·디지털"`, `"생활지도"` 등 자유 |
| `start_date` | 시작일 | `"YYYY-MM-DD"` |
| `end_date` | 종료일 | `"YYYY-MM-DD"` (하루짜리면 시작일과 같게) |
| `time` | 시간 | `"15:00~17:00"` |
| `mode` | 방식 | `온라인` / `오프라인` / `혼합` |
| `location` | 장소 | `"연수원 3층 강당"`, 온라인이면 `"원격"` |
| `target` | 대상 | `"초등 교사"` |
| `hours` | 이수시간(숫자) | `15` |
| `apply_deadline` | 신청 마감일(이날까지 신청 가능) | `"YYYY-MM-DD"` |
| `apply_url` | 신청 페이지 주소(구글 설문지 등) | `"https://..."` (비워 두면 "신청 준비 중") |
| `updated_at` | 이 항목을 고친 날짜 | `"YYYY-MM-DD"` (가장 최근 값이 "마지막 업데이트"로 표시) |

### 화면 표시 규칙
- `published`가 `false`인 연수는 보이지 않아요.
- 신청 마감일이 지나면 **마감** 배지가 붙고 기본 목록에서 빠져요("마감된 연수도 보기"로 볼 수 있어요).
- `apply_url`이 있으면 **신청하기** 버튼이 새 탭으로 열리고, 없으면 **신청 준비 중**으로 보여요.
- 신청자 응답은 이 사이트에 저장되지 않아요. 연수마다 구글 설문지 같은 신청 양식을 만들어 `apply_url`에 넣어 주세요.

### 예시 (README 설명용 예시예요. 실제 데이터 아님)

```json
[
  {
    "id": "2026-001",
    "published": true,
    "title": "예시: 초등 AI 디지털교과서 활용 연수",
    "description": "수업에 바로 쓰는 AI 디지털교과서 기능을 실습해요.",
    "organizer": "예시 교육연수원",
    "category": "AI·디지털",
    "start_date": "2026-11-10",
    "end_date": "2026-11-24",
    "time": "자율 수강",
    "mode": "온라인",
    "location": "원격",
    "target": "초등 교사",
    "hours": 15,
    "apply_deadline": "2026-11-05",
    "apply_url": "https://forms.gle/example",
    "updated_at": "2026-10-27"
  }
]
```

## 사이트 기능
- 신청 가능한 연수 목록(신청 가능 → 준비 중 → 마감 순), 마감 D-day
- 2주 안에 마감되는 연수 모음
- 검색, 분야 필터, 마감된 연수 보기
- 목록 / 달력 보기, 클릭하면 상세 보기와 신청하기 버튼
